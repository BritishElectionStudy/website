# British Election Study website prototype

A build-free, static prototype of the agreed BES homepage, with About, Analysis and Data pages. Open `index.html` in a browser or run `python3 -m http.server 8000` and visit `http://localhost:8000`.

The carousel, navigation and local analysis search work in the browser. The Data page links to the current BES data page. The article titles, dates, bylines and generated images are illustrative placeholders, not published findings; replace them with reviewed, properly licensed content before launch. The site has no content management system, analytics or production hosting configuration yet.

Design uses the original BES logo, locally bundled fonts, exact logo navy `#1D3763` and generated prototype photographs from the approved mockup. Images and text are separate from the page layout. Edit the story list in `app.js`, the styles in `styles.css`, and the shared shell in the HTML files. The logo and fonts are provided for BES use; confirm licensing before distribution outside the project.
